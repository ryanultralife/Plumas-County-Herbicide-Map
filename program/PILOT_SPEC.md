# Pilot Specification — Voluntary Trials

**A pilot happens only if a landowner or agency chooses it.** This document is the measurement design so results can pass or fail cleanly.

---

## 1. Purpose of a pilot

1. Measure **real** MBF, costs, residual structure, regen, and chemical use under the Plumas Working Forest Standard.  
2. Compare to a **baseline** (adjacent clearcut+plant unit, same ownership historical average, or documented counterfactual).  
3. Publish aggregate results: **support / do not support** industrial viability for that context.

No pilot → no proof. Opinions do not replace deck scale tickets.

---

## 2. Recommended pilot types

| ID | Land | Size (guidance) | Why |
|---|---|---|---|
| **P1** | Private industrial or family timberland | ~50–300 ac commercial entry | Real THP path, real markets |
| **P2** | USFS or mixed ownership fuels/timber unit near community corridor (e.g. Quincy / Portola / Greenville area) | Per NEPA unit | Public transparency + utilization |

One of each is ideal; one good pilot beats three vague MOUs.

---

## 3. Design requirements

1. Written prescription meeting PRESCRIPTION_STANDARD.md (matrix, gaps, skips, chemical hierarchy).  
2. **Pre-harvest** inventory summary.  
3. Identified **mill/biomass offtake** (letter or contract — even if contingent).  
4. **Baseline comparator** defined in writing before first tree.  
5. Monitoring budget (who pays is owner/agency decision; unpaid monitoring = weak pilot).  
6. Agreement on what may be published (aggregates vs confidential stumpage).

---

## 4. Success / fail metrics

| Metric | Pass (example thresholds — set final numbers in pilot charter) | Fail signal |
|---|---|---|
| Broadcast herbicide | **0** lbs planned and applied | Any broadcast free-to-grow |
| Spot chemical | Disclosed if used; minimized | Hidden or unit-wide “spot” in name only |
| MBF removed | Meets sale/pre-cruise target band | Severe shortfall or unmarketable sorts |
| Residual forest character | Matrix still forest; gaps within size caps | Unit reads as clearcut |
| Regen year 3–5 | Meets agreed stocking | Failure without adaptive plan |
| Owner economics | Owner states acceptable after actuals | Owner states would not repeat |
| Mill | Wood accepted | Rejected/stranded volume |
| Safety / compliance | No major violations | Serious FP/OSHA issues |

**Program-level honesty:** If owner economics fail but ecology looks good, report: *“Silviculture viable; business case not accepted by this owner.”* That is a fail for industrial scale-up, not a cover-up.

---

## 5. Timeline (typical)

| Phase | When |
|---|---|
| Charter + offtake + baseline | Months −6 to 0 |
| Harvest | Year 0 |
| Immediate post metrics | Year 0–1 |
| Regen / release actions | Years 0–3 |
| Stocking survey | Years 3 and 5 |
| Public summary | After harvest actuals; update at year 3 |

---

## 6. What the Collective provides (if asked)

- Standard text and measurement checklist.  
- Optional public summary page on spraymapca (facts only).  
- Chemical context from PUR for the county.  

**Not provided unless separately funded:** layout, marking, logging, NEPA, THP prep, cash.

---

## 7. Exit and learning

- Either party may stop after the entry; publish what was learned.  
- Failed pilots are **assets** if documented — they prevent false scale-up claims.
