SUBJECT: California Public Records Act request - pesticide permit holder names (Yuba county code 58)

Dear Commissioner Scheer,

Under the California Public Records Act (Gov. Code section 7920.000 et seq.), I request copies of the following public records held by your office:

1. The roster of Operator Identification Numbers / Restricted Materials Permit numbers issued by Yuba County (county code 58), together with the permittee / operator name (business or individual) and mailing city/ZIP for each, for permits active at any time during 2020-2026.

2. If maintained as such, your "Permits, Sites, and Commodities" export or the equivalent CalAgPermits PERMIT QUERY covering the same period.

The purpose is to attach real operator names to California Pesticide Use Report records, which CDPR publishes only as coded permit numbers. We map this data at https://www.spraymapca.org. We are not requesting confidential application-site detail beyond what is already public in the PUR, only the operator-ID to name correspondence. Sutter County's public permit layer already names some Yuba-issued permits that work Sutter ground; the Yuba roster itself would name the rest.

Preferred format: a machine-readable file (CSV or Excel). A column of operator/permit IDs and a column of names is sufficient. Several counties have provided exactly this as a CalAgPermits "Permits, Sites and Commodities" export, which takes a few minutes to run.

Fee waiver / costs: this request serves the public interest in government transparency; please waive duplication fees if possible. If costs will exceed $25, please contact me first with an estimate.

Please let me know within the 10-day statutory period (Gov. Code section 7922.535) whether the records exist and when they will be produced. If any portion is withheld, please cite the specific exemption.

Thank you,
