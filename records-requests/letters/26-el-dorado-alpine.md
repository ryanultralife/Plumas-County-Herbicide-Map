# Public Records Act request — El Dorado County Agricultural Commissioner (also Alpine)

**To:** LeeAnne Mila, El Dorado County Agricultural Commissioner / Sealer of Weights & Measures
**Send to:** eldcag@edcgov.us
**Also:** El Dorado County Public Records Center (GovQA) if the office prefers portal filing: https://eldoradocountyca.mycusthelp.com
**From:** Taylor Durgan, Executive Director, Plumas Grassroots Collective / SprayMap California <spraymapca@gmail.com>
**Date:** September 19, 2026
**Re:** California Public Records Act request — pesticide permit holder names (El Dorado county code 09 and Alpine county code 02)

Dear Commissioner Mila,

Under the California Public Records Act (Gov. Code § 7920.000 *et seq.*), I request
copies of the following public records held by your office:

1. The roster of **Operator Identification Numbers / Restricted Materials Permit
   numbers** issued by **El Dorado County (county code 09)** and, because your office
   handles Alpine County pesticide permitting, **Alpine County (county code 02)**,
   together with the **permittee / operator name** (business or individual) and
   mailing city/ZIP for each, for permits active at any time during **2020–2026**.

2. If maintained as such, your **"Permits, Sites, and Commodities"** export or the
   equivalent CalAgPermits **PERMIT QUERY** covering the same period.

The purpose is to attach real operator names to California Pesticide Use Report
records, which CDPR publishes only as coded permit numbers. We map this data at
https://www.spraymapca.org. We are not requesting confidential application-site
detail beyond what is already public in the PUR — only the operator-ID → name
correspondence.

**Preferred format:** a machine-readable file (CSV or Excel). A column of operator/
permit IDs and a column of names is sufficient.

**Fee waiver / costs:** This request serves the public interest in government
transparency; please waive duplication fees if possible. If costs will exceed $25,
please contact me first with an estimate.

Please let me know within the 10-day statutory period (Gov. Code § 7922.535) whether
the records exist and when they will be produced. If any portion is withheld, please
cite the specific exemption.

Thank you,

Taylor Durgan
Executive Director, Plumas Grassroots Collective
SprayMap California
spraymapca@gmail.com · https://www.spraymapca.org/
